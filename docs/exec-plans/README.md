# Execution Plans

This directory contains implementation plans for approved work. Follow the
[plan rules](../PLANS.md), including the required Status, Progress, Decisions,
and Verification sections.

- [Active plans](active/README.md) contain work that has not finished.
- [Completed plans](completed/README.md) preserve verified implementation
  history.

Design discussion belongs in [design documents](../design-docs/README.md), not
in execution plans.
