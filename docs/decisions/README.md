# Architecture Decisions

This directory contains lasting architecture decision records. An architecture
decision record is a short document that explains an important technical
choice, its context, and its consequences.

Name a record `YYYY-MM-DD-short-title.md`. Link every record from this index and
from any execution plan that depends on it. Do not store temporary progress or
product requirements here.

No separate decision records exist yet. The
[approved foundation design](../design-docs/README.md) records the current
decisions.
